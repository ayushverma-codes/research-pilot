# Research Report

**Goal:** What is the current pricing for Anthropic's Claude API, including the newest models?

**What we can confirm from the available sources**

| Area | What the sources say |
|------|----------------------|
| **Overall pricing presentation** | Anthropic publishes its pricing on a dedicated “Plans & Pricing” page ( `claude.com/pricing` ) and in the “Pricing – Claude Platform Docs” page. The layout separates **subscription plans for the Claude UI** (Free, Pro, Max, Team, Enterprise) from **API usage pricing**, which is expressed in USD **per million tokens (MTok)**. |
| **Subscription plans (UI‑focused)** | • **Free** – $0 – unlimited sign‑ups, limited usage. <br>• **Pro** – $17 / month (annual billing, $200 upfront) or $20 / month if billed monthly. <br>• **Max** – $100 / month. <br>• **Team** – two seat‑levels: **Standard** $20 / seat / month and **Premium** $100 / seat / month; both give larger usage caps than the Pro/Max plans. <br>• **Enterprise** – custom pricing; seat price + usage billed at the API rates. |
| **API‑only pricing** | • Prices are listed **per 1 million tokens** (MTok). <br>• The same token‑rate applies to all current Claude models unless a model‑specific note is made. <br>• A **10 % premium** is added for “regional and multi‑region endpoints” (e.g., for Claude Sonnet 4.5, Haiku 4.5, Opus 4.5 and any later models). <br>• **Batch‑processing discounts** of up to **50 %** are advertised (“Save 50 % with batch processing”). <br>• Prompt‑caching and “fast‑mode” cost‑optimisation options are mentioned but not quantified. |
| **Model lineup (as of 2026)** | • **Haiku 4.5** – the smallest, fastest model. <br>• **Sonnet 5** (also referenced as Sonnet 4.5 in the pricing table). <br>• **Opus 5** and **Opus 5.5** – the most capable, with the note that *Opus 5.5 costs ≈ 40 % less to run than Opus 5*. <br>• **Fable 5.1** – the newest “knowledge‑work” model, released alongside Opus 5.5. <br>All four models are listed in the “Claude Pricing 2026” tech‑news roundup, which also mentions that the pricing table on the official site covers these models. |
| **Marketplace / cloud‑partner pricing** | • When Claude is accessed through **AWS Marketplace** (Claude Consumption Units) or **Microsoft Foundry**, the token usage is still billed in USD at Anthropic’s standard rates, but the exact conversion to CCUs is not disclosed in the findings. <br>• For **Amazon Bedrock** and **Google Cloud**, the official pricing pages of those platforms should be consulted; the Anthropic docs simply point to those external pages. |
| **Recent pricing‑related announcements** | • The **Anthropic newsroom** announced that *Opus 5.5 performs at the level of Claude Fable 5.1 but costs 40 % less to run*. No absolute dollar amount is given. <br>• No new “tier” (e.g., “Pro‑API”) or price‑change announcement is shown in the scraped material. |

### What *is not* available in the findings

- **Exact per‑million‑token rates** for each model (e.g., “$X per MTok for Haiku 4.5, $Y per MTok for Opus 5”).  
- **Detailed tier‑by‑tier breakdown** of API usage limits or overage fees for the Free/Pro/Max plans.  
- **Specific numbers for batch‑processing or prompt‑caching discounts** (the existence of a 50 % batch discount is mentioned, but the baseline price to which the discount applies is missing).  
- **Regional endpoint price tables** (the 10 % premium is noted, but the base price it augments is not provided).  

Because the source material does not include these concrete figures, we cannot supply a numeric “current price list” for the Claude API.

---

## Bottom‑line answer

- Anthropic’s **Claude API** is billed **per 1 million tokens** in USD.  
- The **official pricing page** ( `claude.com/pricing` ) lists the models **Haiku 4.5, Sonnet 5 (or 4.5), Opus 5/5.5, and Fable 5.1** under this token‑based scheme.  
- A **10 % surcharge** applies to regional endpoints, and a **up‑to‑50 % batch‑processing discount** is available.  
- **Opus 5.5** is advertised as **≈ 40 % cheaper to run than Opus 5**, but no absolute dollar amount is disclosed.  
- For the **non‑API UI plans**, the current published subscription fees are **Free ($0), Pro ($17‑$20 / month), Max ($100 / month), Team ($20‑$100 / seat / month), and Enterprise (custom)**.

**Because the exact per‑token pricing numbers are not present in the gathered findings, we cannot provide the precise current USD cost for each Claude model’s API usage.** To obtain the exact figures, you would need to visit the live pricing page (`claude.com/pricing`) or the detailed “Pricing – Claude Platform Docs” page referenced above.
