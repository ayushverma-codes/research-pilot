## Key Findings

- Claude API pricing (Sept 2026) is listed as **$1‑$50 per 1 M tokens** across all models.  
- **Fable 5**: $10 / $50 per M tokens (input / output).

- **Opus 5.5**: marketed as **40 % less expensive** to run than Opus 5.  
- Prompt‑caching **reduces input costs by up to 90 %**; a cache hit costs **$0.25 USD per M tokens** (2.5 % of the standard input price) for Claude Fable 5.1/Claude Mythos 5.1.  
- **Batch API** provides a **flat 50 % discount** on token pricing.  
- Regional/multi‑region endpoints for Claude Sonnet 4.5, Haiku 4.5, and Opus 4.5 incur a **10 % premium** over global endpoints.  
- Subscription plans (Free, Pro $17/mo, Max $100/mo, Team $20‑$100 per seat) are listed on claude.com/pricing, but do not specify per‑token API rates.

## Comparison / Analysis

The token‑based pricing scales with model capability: the most capable model (Fable 5) commands the highest per‑token cost, while the lightweight Haiku 4.5 is the cheapest. The introduction of Opus 5.5, priced 40 % lower than Opus 5, indicates a shift toward more cost‑effective high‑performance models, though the exact per‑token rate remains unspecified. Regional pricing premiums add another layer of cost variability for deployments on specific cloud endpoints.
