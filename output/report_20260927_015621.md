### Additional notes that appear in the official docs

| Item | Detail (as stated in the findings) |
|------|-------------------------------------|
| **Regional‑endpoint premium** | Starting with **Claude Sonnet 4.5, Claude Haiku 4.5 and Claude Opus 4.5**, regional (multi‑region) endpoints carry a **10 % price premium** over the default global endpoint. The table above (which lists the global‑endpoint rates) therefore needs a 10 % uplift for those regional endpoints. |
| **Other Claude 3.x models** | The pricing page lists “Claude 3 Opus, Sonnet, Haiku” among the available models, but the PDF that provides the numeric table only includes the newer 4.x SKUs (Opus 4.6/4.7). No per‑token numbers for the Claude 3 family are given in the supplied sources. |
| **Marketplace / cloud‑partner pricing** | When the API is accessed via Anthropic‑operated platforms that are billed through a cloud marketplace (e.g., **AWS Marketplace** or **Microsoft Foundry**), usage is invoiced in **Claude Consumption Units (CCU)** rather than directly in USD per token. The exact CCU‑to‑USD conversion is not disclosed in the provided material. |
| **Availability on third‑party clouds** | Claude models (including the newest ones) are also offered on **Amazon Bedrock** and **Google Cloud**. Pricing on those platforms follows the respective cloud‑provider marketplace terms and is therefore not captured in the Anthropic‑direct API table. |
| **Free / lower‑tier plans** | Anthropic’s “Plans & Pricing” page mentions free, Pro, Max, Team and Enterprise tiers for the Claude **platform**, but the specific token‑price values for the API‑only tier are only those shown in the PDF. No free‑API token allocation is listed in the findings. |
| **Tool‑use token overhead** | Declaring a default toolset adds roughly **4 500 input tokens** to every request (≈ 4 520 on larger Opus models, ≈ 4 590 on Sonnet). This overhead should be considered when estimating costs, but it does not affect the per‑token price itself. |

### How to read the numbers

* **Input‑token price** is what you pay for the tokens you send to Claude (the prompt).  
* **Output‑token price** is what you pay for the tokens Claude generates in its response.  
* **Cache‑write / cache‑hit rates** apply when you enable Claude’s caching feature; they are charged per 1 M tokens of cache activity.  
* **Batch‑processing rates** are lower because they assume higher‑volume, non‑real‑time usage.

### Bottom line for “current pricing”

- The **most recent, fully‑specified per‑token rates** that are publicly documented are for **Claude Opus 4.6** and **Claude Opus 4.7** (both with identical token prices).  
- Those rates are **$5 / M input tokens** and **$25 / M output tokens** for the standard global tier, with a 10 % uplift for regional endpoints and lower rates for US‑only or batch‑processing tiers.  
- Pricing for the **Claude 3 series (Opus, Sonnet, Haiku)** and for **Claude 4.5 models** is mentioned qualitatively (regional premium, availability on Bedrock/Google Cloud) but **exact per‑token numbers are not included** in the supplied sources.  

If you need the exact per‑token costs for Claude 3 Opus / Sonnet / Haiku or for Claude 4.5 models, the official Anthropic pricing page (https://claude.com/pricing) or the cloud‑partner marketplace listings would have to be consulted, as the current findings do not contain those figures.
